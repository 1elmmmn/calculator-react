# Калькулятор (React + TypeScript)

![CI](../../actions/workflows/ci.yml/badge.svg)

Калькулятор на React 19 и TypeScript с собственным разбором выражений: `eval()` не используется. Есть проценты как на обычном калькуляторе, история вычислений, ввод с клавиатуры и светлая/тёмная тема по настройке системы.

## Возможности

- Четыре действия с правильным приоритетом: `2 + 3 × 4 = 14`
- Проценты как на обычном калькуляторе: `200 + 10% = 220`, `200 × 10% = 20`, `50% = 0,5`
- Без «шума» чисел с плавающей точкой: `0,1 + 0,2 = 0,3` (а не `0.30000000000000004`)
- Понятные ошибки: деление на ноль, слишком большое число
- Ввод мышью и клавиатурой: цифры, `+ - * / %`, `Enter`, `Backspace`, `Esc`; нажатая клавиша подсвечивается на экране
- Выражение выводится читаемо: `1 250 × 12 + 8%`, запятая как десятичный разделитель, разряды через пробел
- Продолжение вычислений с результата, история последних 10 вычислений (сохраняется в браузере), копирование результата
- Адаптивная вёрстка и доступность: подписи у всех кнопок, видимый фокус, объявление результата для скринридеров (`role="status"`), `prefers-reduced-motion`

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm test           # тесты (Vitest + Testing Library)
npm run lint       # ESLint
npm run build      # проверка типов и сборка в dist/index.html
```

`npm run build` создаёт **один самодостаточный файл** `dist/index.html` (JS и CSS встроены). Его можно открыть двойным кликом или выложить на любой хостинг.

## Стек

React 19 (хуки, без классов), TypeScript в строгом режиме (`strict`, `noUncheckedIndexedAccess`), Vite, Vitest + React Testing Library + user-event, ESLint (включая правила хуков), GitHub Actions (CI и деплой на GitHub Pages).

## Структура

```
src/
  App.tsx                 состояние приложения, клавиатура, копирование
  components/
    Display.tsx           экран: выражение, результат, кнопка «копировать»
    Keypad.tsx            клавиши
    History.tsx           история вычислений
  hooks/
    useHistory.ts         история в localStorage (проверка сохранённых данных)
    useLocalStorage.ts    состояние, которое сохраняется
    useTransient.ts       короткие подсветки: «нажато», «скопировано»
  lib/
    math.ts               разбор и вычисление выражений, форматирование (чистые функции)
    state.ts              правила ввода: press(state, key) → новое состояние
    keys.ts               клавиши клавиатуры → команды
    storage.ts            безопасная обёртка над localStorage
```

## Как это устроено

**Разбор выражений вместо `eval()`.** Выражение разбивается на токены и считается рекурсивным спуском по грамматике:

```
выражение := слагаемое (('+' | '-') слагаемое)*
слагаемое := множитель (('*' | '/') множитель)*
множитель := '-'* число '%'*
```

Приоритет операций следует из самой структуры грамматики. Любой посторонний ввод даёт ошибку `syntax`, поэтому выполнить произвольный код через калькулятор невозможно.

**Состояние как чистая функция.** `press(state, key)` не меняет старое состояние, а возвращает новое. Поэтому все правила ввода тестируются без браузера и без React, а компоненты остаются тонким слоем над ними.

**Точность.** Каждый результат округляется до 15 значащих цифр: этого достаточно, чтобы убрать шум двоичных дробей, и при этом целые числа до 10¹⁵ остаются точными.

**Безопасность хранилища.** Всё, что читается из `localStorage`, считается недоверенным: записи истории проверяются перед использованием.

## Тесты

38 тестов: вычисления (приоритет, проценты, округление, ошибки), правила ввода, форматирование, проверка сохранённых данных и сам интерфейс (ввод кнопками и с клавиатуры, история, копирование, объявления для скринридеров).

## Публикация на GitHub Pages

1. Загрузите проект в репозиторий (папки `node_modules` и `dist` загружать не нужно, они в `.gitignore`).
2. Settings → Pages → **Source: GitHub Actions**.
3. После `git push` в ветку `main` workflow `deploy.yml` прогонит тесты, соберёт проект и опубликует его.
